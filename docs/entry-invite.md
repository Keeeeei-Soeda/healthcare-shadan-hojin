# 受付開始の案内メール（entry-invite）

10/4 の登録者に、受講・研修のお申し込み受付（[`apply.md`](apply.md)）が始まったことをメールで知らせる。

| 項目 | 内容 |
|---|---|
| Apps Script | `google-apps-script/entry-invite.gs`（単独のプロジェクト `entry-invite`、所有者 `info@iha-as.com`）<br>https://script.google.com/d/1RdNSIeNXtP7Ta-vjheya5WYQdi-UQ1Vdsn5YXwRDIU3Y7O7xy7J3HRZb/edit |
| 送り先 | 10/4 の整理券・キャンセル待ち・投影用ウェイティングの6タブ（読み取りのみ） |
| 送信元 | `info@iha-as.com` の Gmail（返信はそのまま協会に届く） |
| 送信記録 | `案内メール_送信記録` タブ（初回の `sendInvites` で作成） |

## 文面（4種類）

| | 整理券の方 | ウェイティングの方（キャンセル待ち・投影用） |
|---|---|---|
| 管理士 | 整理番号を本文に記載。リンクを開くと整理券番号が入力済み | 受付順を本文に記載。「整理券を持っていない」にチェックする旨（リンクを開くとチェック済み） |
| 医療機関 | 同上 | 同上 |

共通：受付開始（10/8）のお知らせ、申込ページへのリンク、料金（税別）、お申し込み後の流れ（振込先は申込後にメール・10/20〜10/31 に振込 など）。文面は `buildMail_` と `PROGRAMS` で変える。

## 送り先の決め方

- 氏名とメールがある行だけ（整理券タブの未発行の行は対象外）
- 同じ制度で同じメールが複数のタブにあるときは1通だけ。整理券の文面を優先する
- 制度が違えば別々に送る（管理士と医療機関の両方に登録した人には2通）
- すでに申し込んだ人（`申込_管理士`／`申込_医療機関` に同じメールがある人）には送らない
- `案内メール_送信記録` で「送信済」の人には送らない。何度 `sendInvites` を実行しても二重には送らない

## 手順

1. （開発）`clasp --user iha` でプロジェクト `entry-invite` を作成し、コードを送る
2. エディタで `sendTestInvites` を実行 → 権限を承認 → `info@iha-as.com` に4種類のテストメールが届くので文面を確認
3. `previewInvites` を実行 → ログで送り先の一覧と件数を確認（送信はしない）
4. `sendInvites` を実行 → 全員に送信。結果は `案内メール_送信記録` タブとログで確認

Gmail の1日の送信上限に達した場合は、送れた分だけ記録して止まる。翌日以降にもう一度 `sendInvites` を実行すると、残りの人にだけ送る。

`送信失敗` になった人は記録に残るが「送信済」ではないため、次に `sendInvites` を実行したときに再送される。
