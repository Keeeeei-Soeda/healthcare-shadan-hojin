# 再利用テンプレート: スプレッドシート → 複数宛先メール通知

他プロジェクトでも使える汎用 GAS です。

```
スプレッドシートに新しい行が入る
        ↓
内容を表形式に整理
        ↓
複数メールアドレスへ通知
```

テンプレート本体: `google-apps-script/templates/sheet-email-notify.gs`

---

## 向いている用途

- Googleフォームの回答をシートで受けて担当者に通知
- サイトのお問い合わせをシート連携して通知
- 別ツールがシートに追記したときの社内通知

この協会サイト本番の問い合わせ処理は、より特化した  
`google-apps-script/contact-to-sheet.gs` を使っています（自動返信あり）。  
**新規プロジェクトでは本テンプレートをコピーする方が簡単です。**

---

## セットアップ（5分）

### 1. スプレッドシートを用意

1. 新規または既存のスプレッドシートを開く
2. 通知したいタブ名を決める（例: `contact_form`）
3. 1行目にヘッダーを入れる（例: 受付日時 / お名前 / メール / 内容）

### 2. Apps Script を作成

1. スプレッドシート → **拡張機能** → **Apps Script**
2. `sheet-email-notify.gs` の内容をすべて貼り付け
3. 上部の設定をプロジェクト用に変更

```javascript
const SHEET_NAME = 'contact_form';     // 監視するシート名
const MAIL_FROM_NAME = 'お問い合わせ通知';
const SUBJECT_PREFIX = '【新規データ通知】';
const NOTIFY_TO_FALLBACK = '';         // 直書きも可。空ならプロパティ必須
```

### 3. 通知先を設定（複数可）

**プロジェクトの設定** → **スクリプト プロパティ**

| プロパティ | 値の例 |
|---|---|
| `NOTIFY_TO` | `a@example.com, b@example.com, c@example.com` |

※ プロパティ名は1つ。複数アドレスは **カンマ区切り**。

任意:

| プロパティ | 意味 |
|---|---|
| `SYNC_TOKEN` | Webアプリ POST を使う場合の簡易トークン |

### 4. 権限承認とトリガー登録

1. 関数 `setupSheetNotify` を選択して **実行**
2. 「権限を確認」→ 許可（スプレッドシート + メール）
3. 実行ログに「セットアップ完了」が出ればOK

> `authorizeMail` だけ先に実行してもメール権限は取れます。  
> `doGet` では承認ダイアログが出ません。

### 5. 動作確認

1. 対象シートにテスト行を1行追加
2. 数十秒待って通知メールが届くか確認
3. 末尾の **通知ステータス** 列が `送信済 (N件)` になるか確認

届かない場合は `notifyNow` を手動実行し、実行ログとステータス列を見てください。

---

## 仕組み

| 項目 | 内容 |
|---|---|
| 検知 | `onChange` トリガー（行追加・編集など） |
| 送信 | `MailApp.sendEmail`（複数宛先は1通の To にまとめて送信） |
| 重複防止 | `通知ステータス` 列が `送信済` の行は再送しない |
| 本文 | ヘッダー行をラベルにした表形式 |

---

## Webアプリ連携（任意）

自サイトのフォームから直接追記＋通知したい場合:

1. **デプロイ** → **新しいデプロイ** → 種類: ウェブアプリ
2. 実行ユーザー: 自分 / アクセス: 全員
3. URL に POST（`Content-Type: text/plain`）

```bash
curl -X POST 'https://script.google.com/macros/s/xxxxx/exec' \
  -H 'Content-Type: text/plain;charset=utf-8' \
  --data-binary '{"token":"","fields":{"お名前":"山田","内容":"テスト"}}'
```

## 他プロジェクトへ持ち込むときのチェックリスト

- [ ] `SHEET_NAME` をそのブックのタブ名に合わせた
- [ ] `NOTIFY_TO` に正しいメールをカンマ区切りで入れた
- [ ] `setupSheetNotify` を実行してトリガー登録した
- [ ] テスト行でメール受信を確認した
- [ ] 迷惑メールフォルダも確認した

## この協会サイトとの違い

| | 本番 `contact-to-sheet.gs` | 本テンプレート |
|---|---|---|
| 目的 | 協会サイト問い合わせ専用 | どのシートでも使える |
| 自動返信 | あり（問い合わせ者へ） | なし（必要なら追加） |
| 通知先プロパティ | `ASSOCIATION_NOTIFY_TO` | `NOTIFY_TO` |
| シート監視トリガー | なし（Web POSTのみ） | あり（`onChange`） |

本番問い合わせの改修は引き続き `contact-to-sheet.gs` を編集してください。
